
# AI Research Agent

An AI-powered research assistant that automates market and business research.

The application searches the web for relevant information, analyzes findings using OpenAI GPT models, and generates structured research reports with source references.

## Features

- Web research using Tavily Search
- AI-powered report generation
- Executive summaries
- Market trend analysis
- Opportunity and risk identification
- Source attribution
- Streamlit-based user interface

## Tech Stack

- Python
- Streamlit
- OpenAI API
- Tavily Search API
- dotenv

## Use Cases

- Market research
- Competitor analysis
- Industry trend analysis
- Business intelligence
- Consulting support

## Setup

1. Clone repository
2. Create virtual environment
3. Install requirements
4. Add API keys to `.env`
5. Run Streamlit app

```bash
streamlit run app.py
